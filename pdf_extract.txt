MÉDIO
Ao scrollar, o banner ter efeito parallax: o background-text "PROJETOS" e a foto central se movem
em velocidades diferentes.
Como fazer: Hook useScrollPosition + transformações CSS com translateY baseado no scroll.
3. Gradiente animado no fundo
FÁCIL
Um gradiente de cores (roxo → azul → roxo) que se move lentamente no fundo do banner.
Como fazer: background: linear-gradient(...) com background-size: 200% 200% e @keyframes
animando a posição do background.
CSS
@keyframes gradientShift {
  0%   { background-position: 0% 50%; }
  50%  { background-position: 100% 50%; }
  100% { background-position: 0% 50%; }
}
