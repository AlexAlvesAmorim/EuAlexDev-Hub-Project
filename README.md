# Dev. de Favela Hub — Portfólio do Alex

Fala, sou o **Alex Alves Amorim**, de Jacarepaguá — RJ. Passei 21+ anos no suporte técnico (do N1 ao N3) ouvindo gente frustrada com sistema que deveria ajudar. Um dia cansou. Resolvi ser quem faz a interface que não atrapalha.

Esse hub é minha vitrine. Não é template. O carrossel 3D ali em cima foi feito na mão, puro CSS + `requestAnimationFrame`, sem biblioteca. Cada card tem história — problema real, solução, perrengue técnico e o que de fato foi entregue.

### O que tem aqui

- **ALFA PDF Reader** — meu xodó. Leitor de PDF pra Windows, em Electron. Mais de 200 pessoas usam. Já passei madrugada debugando impressão silenciosa numa Epson L3150 pra fazer funcionar de verdade. Hoje é leve (~100MB), atualiza sozinho e não fica te enchendo de popup.
- **Fabulosa E-Commerce** — primeira loja que vendi. Moda feminina/masculina, back-end com Fastify + Prisma, depois virou base pro Analyser. Foi a prova que dava pra viver disso.
- **99Food Analyser** — dashboard que transforma planilha bagunçada em decisão. Fiz boa parte sem internet, no seco. Receita por Pix/cartão, ticket médio, melhor dia da semana.
- **Alfa Curriculum Maker** — currículo conversando com chat. 7 modelos em PDF e Word, foto com IA no navegador, sem mandar nada pra servidor. Porque quem precisa de emprego não tem que pagar pra fazer currículo.
- **Este hub** — o próprio portfólio. 10 arquivos CSS separados, 2 hooks, acessibilidade de verdade (teclado, `prefers-reduced-motion`, foco).

### Rodando local

```bash
npm install
npm run dev     # http://localhost:5174
npm run build   # gera o dist/
```

Feito com React + TypeScript + Vite + Tailwind. Nada de framework pesado. Se der `tsc` erro, me avisa que eu arrumo.
